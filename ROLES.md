# Открытый набор до лимита ролей

Версия **0.11** · черновик · обновлено 28.08.2026

Документ про **то, из кого собирается толпа**: полный ростер ролей, из чего
складывается билд и по каким правилам роли попадают в забег.

Замысел игры — [project.md](project.md). Петля и цель под тест VOODOO —
[PROTOTYPE.md](PROTOTYPE.md). Что уже собрано и работает — [GAMEPLAY.md](GAMEPLAY.md).
Числа текущего баланса — [BALANCE.md](BALANCE.md).

Документ описывает **следующую систему, а не текущую**. Она расходится с тем,
что собрано: сейчас три класса и кап в 15 слотов ([project.md](project.md) §1–2),
здесь — 20 ролей и отсутствие потолка численности. Разработка идёт в ветке `roles`.

## 1. Слои билда

| Слой | Что это | Как влияет |
|---|---|---|
| **1. Роли** | Кто состоит в толпе и в каком количестве | Больше голов — больше размер толпы, но и больше открытых точек для урона по толпе |
| **2. Статы поверх роли** | Апгрейд уже набранной роли тирами, без роста числа юнитов | Альтернатива слою 1: толпа остаётся компактной, но сильнее. Без дерева эволюций, прогресс строго линейный |
| **3. Синергия** | Каждый отдельный чел роли X даёт всей толпе небольшой прирост к своей характеристике | Чем больше таких челов, тем больше суммарный прирост |

Артефакты как четвёртый слой билда не спроектированы — см. §6.

## 2. Ростер ролей — 20

### 2.1. Ближний бой — внешнее кольцо, 7 ролей

| Роль | Архетип | Что делает | Синергия |
|---|---|---|---|
| **Мужик с лопатой** | база | Атака по одной цели, стандартный темп | шанс на более высокий тир карточки |
| **Молотобоец** | умножитель · круг | Урон по площади вокруг себя, медленно, с нокбэком | + шанс оглушить |
| **Копейщик** | умножитель · линия | Пробивает 2–3 цели по прямой линии | + дальность атаки |

| **Щитоносец** | управление пространством | Слабый удар, но сильно отталкивает цель | + снижение получаемого урона / − скорость толпы |
| **Тяжеловес** | редкий тяжёлый удар | Редкий мощный удар, сбивает с ног элитных врагов | + урон ближнего боя |

## 3. Типы карточек и редкость

Толпа собирается в первую очередь **через добавление людей** — это основной
рычаг, статы поверх роли вторичны. Каждая карточка на level-up — это тип
(кого/что улучшаем) и уровень редкости (насколько сильно), оба выбираются
случайно и независимо.

**Тип А — «+ человек роли X».** Добавляет юнитов роли X в толпу: толпа растёт
числом. Количество зависит от редкости карточки.

**Тип Б — «+ стат роли X».** Апгрейд тира уже взятой роли X — усиливает то, что
для неё главное: для одной роли это урон, для другой шанс крита, для третьей
сила отталкивания и так далее, своя характеристика для каждой роли, без общей
разбивки. Величина прироста зависит от редкости карточки, число тиров — от
потолка роли.

| Редкость | Тип А — человек | Тип Б — стат |
|---|---|---|
| Обычная | +1 юнит | небольшой прирост |
| Редкая | +2 юнита | средний прирост |
| Эпическая | +3 юнита | крупный прирост |

**Численность толпы не ограничивается.** Вместо потолка камера постепенно
отдаляется, чтобы толпа любого размера помещалась на экране.

## 4. Формирование забега

Ограничение работает **не запретом на рост толпы, а сужением пула ролей**,
из которых она растёт.

| Момент | Правило |
|---|---|
| **Старт забега** | Фиксированных стартовых персонажей нет. Игроку показывают случайную выборку из 14 боевых ролей — ближний и дальний бой, включая Мужика с лопатой и Копа. Поддержка на старте не предлагается |
| **Level-up** | 3 случайные карточки. Каждая — тип «человек / стат» и уровень редкости, оба случайны |
| **Пока лимит ролей не набран** | Карточки «+ человек» могут предложить любую из 20 ролей — так толпа знакомится с новыми ролями |
| **Лимит ролей набран — 6** | Карточки «+ человек» продолжают выпадать, но только из уже полученных ролей: толпа растёт числом, не разнообразием |
| **Потолок тиров на роль — 5** | У каждой роли свой предел карточек «+ стат». После потолка её статовые карточки пропадают из пула — роль продолжает расти только числом юнитов |

## 5. Враги

Каждый тип нагружает конкретную механику билда — не осталось ни одной
роли-категории, которая была бы бесполезна против всех врагов сразу.

| Тип | Угроза / что работает против |
|---|---|
| **Мелкие многочисленные** (пауки) | Слабые поодиночке, но массово забивают точки контакта числом — умножители (круг/линия/цепь/конус) рвут их эффективнее заполнителей |
| **Средние зомби** | Базовый противник, стандартные HP и урон — ничего специфичного не требует |
| **Большие зомби** | Много HP, мало точек контакта на одну тушу — нужен редкий тяжёлый удар, числом бойцов не продавить |
| **Очень быстрые** | Резко закрывают дистанцию, застают врасплох — нужен контроль/нокбэк, дальность атаки или скорость толпы |
| **Яйцекладущий** (дальний) | Стреляет яйцом с телеграфом — маркер на земле в точке ближайшего чела, секунда полёта до попадания. По маркеру АоЕ-урон, из точки после взрыва вылезает паук |
| **Взрывающиеся при смерти** | Наказывают скопление у точки контакта взрывом после гибели |
| **Таран** (большой) | Медленно ходит → короткая заметная подготовка → быстрый рывок по прямой, пробивает толпу по линии → после рывка недвижим — окно для тяжёлого удара |

## 6. Открытые вопросы

**Четвёртый слой билда.** Артефакты как четвёртый слой не спроектированы.

**Враги в резерве.** Не решено: бронированные / с резистом к типу урона и
элитные, устойчивые к контролю — отложены как слишком сложные для этого захода.
